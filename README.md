Forecasts Twitch viewers for GTA VI's launch day (2026-11-19 UTC), hours 2–24, as five quantiles (5/25/50/75/95%) per hour. Pure Python 3.13 stdlib, offline and deterministic. The model takes the median log-ratio shape of comparable midnight/rolling game launches (10 kept comparables), adjusts it for launch size with a slope that phases in over the morning, and widens the spread with horizon. Leave-one-out pinball loss on the kept comparables: 0.1880, vs 0.2721 for the starter persistence baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output python3 main.py
```
